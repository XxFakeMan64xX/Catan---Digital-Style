Phase 1: Core Game Loop

Dice rolling - Press a key to roll 2 dice, display result
Resource collection - When dice roll matches tile numbers, give resources to players with settlements on those tiles

Phase 2: Building

Settlement placement - Click hex corners to place settlements (cost: 1 wood, 1 brick, 1 sheep, 1 wheat)
Road placement - Click hex edges to place roads (cost: 1 wood, 1 brick)
Building UI - Show current resources and building buttons

Phase 3: Advanced Mechanics

Robber - On roll of 7, move robber to a tile, block production, steal from adjacent player
Victory points - Track settlements (1 VP), cities (2 VP), longest road, largest army
Win condition - First to 10 VP wins
